# Rock Paper Scissors Game

A responsive Rock Paper Scissors game built using HTML, CSS and JavaScript.

## Features

- Play Rock, Paper and Scissors against the computer.
- Best of 5 and Best of 10 game modes.
- Live scoreboard and match progress.
- Game statistics.
- Game history with clear history option.
- Light and Dark themes.
- Sound effects and background music.
- Keyboard shortcuts:
  - R = Rock
  - P = Paper
  - S = Scissors
  - Esc = Close Game History
- Responsive design for desktop and mobile.
- Statistics, history and theme preferences saved in browser storage.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start playing!
